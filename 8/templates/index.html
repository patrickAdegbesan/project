About This System

This system was developed as a Final Year Project at the Department of Computer Science, Caleb University, Lagos. It provides a practical tool for telecommunications engineers and researchers to study how Nigerian urban networks behave under varying traffic loads without risking live service disruption.

The underlying simulation uses SimPy (discrete-event simulation), NumPy (statistical computation), and Matplotlib (visualisation), and is validated against closed-form M/M/1 queuing theory.

Key Features
  • Poisson packet generation (exponential inter-arrivals)
  • Finite FIFO queuing with configurable buffer size
  • Multi-node linear network topology
  • Load testing at 50%, 80%, 100%, 120%
  • Statistical replications for reliability
  • M/M/1 theoretical validation
