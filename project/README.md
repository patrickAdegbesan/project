# Earlier prototype versions (archive)

This folder contains **earlier prototype versions** of three projects,
kept for reference only. They are superseded by the finished versions
in the top-level folders:

| Here | Superseded by | Difference |
|------|---------------|------------|
| `1/complaint-desk/` | [`../1/complaint-desk/`](../1/complaint-desk/) | Prototype is static HTML only — no backend, no API calls. The finished version has a Flask + SQLite backend and a terminal client. |
| `2/index.html` | [`../4/`](../4/) | Earlier revision of the SentinelIQ fraud-detection dashboard with hardcoded data. The finished version has a trained model, Flask API and live data. |
| `3/` | [`../3 (2)/`](../3%20(2)/) | Earlier revision of the Personal Health Monitor app without persistence. The finished version persists data with AsyncStorage and includes a terminal client. |

Nothing in this folder is meant to be run or maintained. If you are
looking for a working project, use the top-level folders.
