# Rehoboth-Winners Shopping Mall — Shop Ownership Landing Page

A professional landing page for the **Rehoboth-Winners Shopping Mall**
development at Bluestone Garden City (proposal Option 2: Basic
Information Website). All payment buttons point to the official
Paystack payment link:

> https://paystack.shop/pay/shop-development-fund

## Page sections

- **Hero** — "Only 4 slots remaining" notice, headline, and a Project
  Summary panel (location, 16 shops, slot price, payment channel).
- **01 The Project** — the 500 sqm plot, 8 shops up / 8 down, estate
  road frontage, Bluestone Garden City context.
- **02 Why Own a Shop Here** — six reasons (lifetime investment,
  rental income, growing community, security, one-stop mall, expert
  support).
- **03 Slots & Pricing** — a live slot-availability grid (available
  slots link straight to the payment page; reserved and sold slots are
  marked), full slot ₦7.5m (2 shops + toilet space), pairing option
  for single shops, and the Stage 1 land-acquisition breakdown table
  (₦50m land + 5% agency + 10% legal + 5% development = ₦60m).
- **04 Project Roadmap** — an interactive treasure-map style path
  through the four stages (land, documentation & design, construction
  to roof level, individual finishing). Completed stages show a check,
  the current stage pulses, and clicking a stop reveals its progress
  bar, contents and any public note. Falls back to a vertical timeline
  on phones.
- **05 Business Ideas** — the 30+ suggested businesses grouped into
  Food & Grocery, Food Service & Leisure, Fashion & Beauty, and
  Services & Retail.
- **06 Enquiries** — phone numbers (0803 334 6916, 0907 719 5867),
  email, and an enquiry form that opens the visitor's email app
  pre-filled (no backend required).
- Fully mobile responsive — phones, tablets and desktops.

## Live data: slots and stage progress

Nothing on the public site is hardcoded. Slot availability ("Only X
slots remaining", the slot grid, the summary panel) and the roadmap's
stage progress are all read from `data/site-data.js`.

### The admin page (`admin.html`)

Open `admin.html` in a browser to manage the project:

1. **Slot status** — click slots to cycle Available → Reserved → Sold.
2. **Payment register** — record each confirmed Paystack payment
   (date, name, email, phone, amount, reference, slot). Records are
   stored in that browser only and exportable as CSV — **they are
   never published to the public site**.
3. **Stage progress** — set each stage's status, percentage and an
   optional public note.
4. **Save & publish** — *Save & Preview* shows the changes on the
   public site in the same browser; *Download site-data.js* generates
   the public data file (slot statuses + stage progress only, no
   personal data). Upload it to the site's `data/` folder to publish.

Keep `admin.html` unlinked/unshared — it carries a `noindex` tag and
never appears in the site navigation. For stronger protection, remove
it from the public host entirely and use a local copy, or protect it
with your host's password/access controls. Back up the CSV exports
regularly, since the payment register lives in the team's browser.

## Tech

Pure static HTML/CSS/JS — no frameworks, no build step, no external
CDNs. The only external destination is the Paystack payment page.

```
shop-development-fund/
├── index.html        # public site
├── admin.html        # project team admin (keep unlinked)
├── data/site-data.js # published slot + stage data (generated by admin)
├── assets/           # og-image.png (link previews) + favicon.svg
├── css/styles.css
└── js/main.js, js/admin.js
```

When the site gets its final domain, set the `og:image` meta tag in
`index.html` to the absolute URL of `assets/og-image.png` so WhatsApp
and Facebook show the preview card when the link is shared.

### Renders and the fly-through video

The hero showcase holds a cinematic fly-through video
(`assets/mall-flythrough.mp4`) and a four-image render gallery. To add
the renders, drop these files into `assets/` (square images, ~1024px):

| File | Shows |
|------|-------|
| `assets/mall-front.jpg` | Front view (also used as the video poster) |
| `assets/mall-aerial.jpg` | Aerial view |
| `assets/mall-dusk.jpg` | Evening / dusk view |
| `assets/mall-frontage.jpg` | Shopfront frontage |

The gallery fills in automatically for whichever files are present; if
none are added yet, it hides itself so nothing looks broken. Replace
the video by overwriting `assets/mall-flythrough.mp4`.

## Running locally

Open `index.html` directly in a browser, or serve the folder:

```bash
cd shop-development-fund
python3 -m http.server 8080   # → http://localhost:8080
```

## Deploying

Upload the folder contents to any static host (cPanel, Netlify,
GitHub Pages, Vercel, etc.). No server-side code is needed.

## Editing common things

- **Slots remaining / stage progress** — use `admin.html` (see above);
  do not edit `index.html` for these.
- **Payment link** — search `index.html` and `js/main.js` for
  `paystack.shop`.
- **Phone numbers / email** — search for `0803` / `sale@301atech.com`
  in `index.html` (the email also appears in `js/main.js`).
- **Colours** — edit the CSS variables at the top of `css/styles.css`.
