# Project 1 — ComplaintDesk

The project lives in the [`complaint-desk/`](complaint-desk/) folder:
a university online complaint management system (Flask + SQLite
backend, HTML/CSS/JS frontend, terminal client).

See [`complaint-desk/README.md`](complaint-desk/README.md) for the
full documentation: features, setup, default accounts, API reference
and the terminal client.

Quick start:

```bash
cd complaint-desk/backend
pip install -r requirements.txt
python app.py        # web app on http://127.0.0.1:5000
python cli.py        # terminal client (same features, same database)
```
