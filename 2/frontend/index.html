About PhishGuard AI

An explainable machine learning system for real-time phishing URL detection, built for security researchers, analysts, and everyday users.

ML Approach

PhishGuard AI uses a gradient-boosted ensemble model (XGBoost + Random Forest) trained on 1.3M labeled URLs. Features span lexical, structural, DNS, and content-based dimensions. SHAP (TreeExplainer) provides post-hoc interpretability for every prediction.

Real-Time Pipeline

  • URL submitted → feature extraction (<50ms)
  • ML inference with confidence calibration
  • SHAP computation for top-5 features
  • Result delivered in under 150ms average

Privacy

Submitted URLs are processed in-memory and not stored beyond session scope unless opted in. No PII is collected. All inference runs on-premises — your data never leaves our infrastructure.

Continuous Learning

User feedback (false positives / negatives) feeds a human-in-the-loop retraining pipeline. Models are evaluated weekly and versioned using MLflow. Current model: GradientBoostingClassifier trained on 30,000 synthetic URL samples.
